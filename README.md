# Dr. Patel's ENT Polyclinic Website

A responsive, modern static website built for an ENT, Speech Therapy, and Hearing Aid Center located in Virar. 

## 🌟 Features
- **Responsive Design:** Looks great on both desktop and mobile devices.
- **Modern UI:** Clean layout, beautiful typography, and custom CSS styling.
- **Creator Details Page:** Includes a dedicated developer contact page.
- **Fast & Lightweight:** Pure HTML and CSS with no heavy frameworks.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Custom Variables, Flexbox, CSS Grid)
